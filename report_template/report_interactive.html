方法与复现

已搜库蛋白定量表 → 鉴定信息过滤 → log2转换及指定归一化 → 样本质控 → limma差异分析 → GO/KEGG、GSEA、GSVA及PPI → 本交互报告。

完整参数、输入校验值、统计模型和软件版本在下方文件中归档。查看完整方法与静态报告。交互页切换、搜索和筛选不改变统计模型或显著性阈值。

GSEA曲线按原始排序和原始基因集重建，构建时逐条核对ES与fgsea输出一致。GSVA使用完整观测基因；不同数据库及比较分别进行BH校正。

数据说明、分析假设与绘图来源

本交互页读取分析结果，不重新计算差异检验或改变显著性阈值。正式差异以流程的 BH 校正 P 和 Fold Change 双阈值判定。未检验不等于无差异。PCA使用全部生物学样本完整观测且非恒定的蛋白；二维距离不能单独作为删除样本的依据。

    图形类别与交互方式参考 AlphaPeptStats 官方文档。实际使用 Plotly.js 3.1.0（MIT）；蛋白/样本详情联动由本项目补充开发，未运行 AlphaPeptStats 的统计分析。Plotly 点击事件文档。
